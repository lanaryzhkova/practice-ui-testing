# UI Testing Practice

Проект автоматизированного тестирования интерфейса сайта [automationteststore.com](https://automationteststore.com/) с использованием Selenium WebDriver и Pytest.

---

## 📋 Тестовые кейсы

### Тест-кейс 1: Проверка сортировки товаров по имени и стоимости

**ID:** TC-001

**Название:** Проверка сортировки товаров по имени и стоимости

**Описание:** Проверить сортировку товаров по имени и стоимости в обоих направлениях (по возрастанию и убыванию) в категории с наличием не менее 4 товаров.

**Предусловие:** 
- Открыт сервис https://automationteststore.com/
- Браузер: Chrome (последняя версия)
- Валюта: US DOLLAR

**Приоритет:** High

**Шаги воспроизведения:**

| # | Шаг | Ожидаемый результат |
|---|-----|---|
| 1 | Открыть вкладку категории товаров "Fragrance" | Отображается список товаров категории с опциями сортировки |
| 2 | Выбрать сортировку по имени "Name A-Z" | Товары отсортированы по имени от A до Z |
| 3 | Выбрать сортировку по имени "Name Z-A" | Товары отсортированы по имени от Z до A |
| 4 | Выбрать сортировку по стоимости "Price Low > High" | Товары отсортированы по цене от низкой к высокой |
| 5 | Выбрать сортировку по стоимости "Price High > Low" | Товары отсортированы по цене от высокой к низкой |

**Файл теста:** `tests/test_sorting_name_price.py`

### Тест-кейс 2: Проверка поисковой выдачи и корзины

**ID:** TC-002

**Название:** Проверка поисковой выдачи и расчёта итоговой суммы в корзине

**Описание:** Проверить функциональность поиска товаров, добавления товаров в корзину, изменения количества товара с наименьшей ценой и корректность расчёта итоговой суммы.

**Предусловие:** 
- Открыт сервис https://automationteststore.com/
- Выбрана валюта "US DOLLAR"
- Браузер: Chrome (последняя версия)

**Приоритет:** High

**Шаги воспроизведения:**

| # | Шаг | Ожидаемый результат |
|---|-----|---|
| 1 | В поисковую строку ввести "shirt" | Поле ввода содержит текст "shirt" |
| 2 | Нажать Enter | Отображается результат поиска с товарами, содержащими "shirt" |
| 3 | Выбрать сортировку по имени "Name Z-A" | Результаты поиска отсортированы по имени от Z до A |
| 4 | Нажать на карточку второго товара | Открывается страница товара с детальной информацией |
| 5 | В поле "Qty" ввести случайное целое положительное число | Введено случайное число (1-10) |
| 6 | Нажать на кнопку "Add to cart" | Товар добавлен в корзину, отображается уведомление |
| 7 | Повторить шаги 1-3: в поиск ввести "shirt", нажать Enter, выбрать "Name Z-A" | Результаты поиска отсортированы |
| 8 | Нажать на карточку третьего товара | Открывается страница третьего товара |
| 9 | В поле "Qty" ввести случайное целое положительное число (1-10) | Введено случайное число |
| 10 | Нажать на кнопку "Add to cart" | Товар добавлен в корзину |
| 11 | Перейти в корзину | Отображается таблица с добавленными товарами |
| 12 | Найти самый дешевый товар в корзине | Определён товар с минимальной ценой |
| 13 | Изменить количество самого дешевого товара: умножить текущее количество на 2 | Новое количество = исходное * 2 |
| 14 | Нажать кнопку "Update" | Корзина обновлена, количество изменено |
| 15 | Проверить итоговую сумму | Итоговая сумма соответствует формуле: (цена 1 × кол-во 1) + (цена 2 × кол-во 2) = ожидаемая сумма |

**Файл теста:** `tests/test_cart_total_with_search.py`

### Тест-кейс 3: Проверка итоговой стоимости товаров после удаления чётных позиций

**ID:** TC-003

**Название:** Проверка итоговой стоимости после удаления чётных позиций из корзины

**Описание:** Добавить 5 случайных товаров с главной страницы в корзину, удалить все чётные по порядку товары и проверить корректность расчёта итоговой стоимости.

**Предусловие:** 
- Открыт сервис https://automationteststore.com/
- Выбрана валюта "US DOLLAR"
- Браузер: Chrome (последняя версия)

**Приоритет:** High

**Шаги воспроизведения:**

| # | Шаг | Ожидаемый результат |
|---|-----|---|
| 1 | Добавить 1-й случайный товар с главной страницы с случайным количеством (1-10) | Товар добавлен в корзину |
| 2 | Добавить 2-й случайный товар с главной страницы с случайным количеством (1-10) | Товар добавлен в корзину |
| 3 | Добавить 3-й случайный товар с главной страницы с случайным количеством (1-10) | Товар добавлен в корзину |
| 4 | Добавить 4-й случайный товар с главной страницы с случайным количеством (1-10) | Товар добавлен в корзину |
| 5 | Добавить 5-й случайный товар с главной страницы с случайным количеством (1-10) | Товар добавлен в корзину |
| 6 | Перейти в корзину | Отображается таблица с 5 товарами |
| 7 | Удалить 2-й товар (чётная позиция) | Товар удалён, в таблице остаётся 4 товара |
| 8 | Удалить 4-й товар (новая чётная позиция) | Товар удалён, в таблице остаётся 3 товара (позиции: 1, 3, 5 исходные) |
| 9 | Проверить итоговую сумму | Итоговая сумма = сумма товаров на позициях 1, 3, 5 (исходные нечётные) |

**Файл теста:** `tests/test_cart_total_with_removals.py`

## 🚀 Установка и запуск

### Требования
- Python 3.10+
- ChromeDriver (совместимый с вашей версией Chrome)
- pip (менеджер пакетов Python)

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Запуск тестов

**Запуск всех тестов:**
```bash
pytest
```

**Запуск конкретного теста:**
```bash
pytest tests/test_sorting_name_price.py
pytest tests/test_cart_total_with_search.py
pytest tests/test_cart_total_with_removals.py
```

**Запуск с параллельным выполнением:**
```bash
pytest -n auto
```

**Запуск с генерацией Allure отчета:**
```bash
pytest --alluredir=allure-results
```

**Просмотр Allure отчета:**
```bash
allure serve allure-results
```
